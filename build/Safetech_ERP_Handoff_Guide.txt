================================================================================
  SECTION 7: ELEMENT TRACEABILITY FLOW (AUTOMATIC 8-STAGE LIFECYCLE)
================================================================================

  Every precast element automatically receives timestamps as it progresses:

  Stage 1: PLANNING     -->  PlanningPage.tsx saves element schedule
                              stamps planning_timestamp
                                    |
  Stage 2: CASTING      -->  ProductionPage.tsx logs concrete pour
                              stamps casting_timestamp
                                    |
  Stage 3: QC           -->  ProductionPage.tsx QC checklist pass
                              stamps qc_timestamp
                                    |
  Stage 4: CURING       -->  ProductionPage.tsx auto-logs
                              stamps curing_timestamp
                                    |
  Stage 5: STOCKYARD    -->  QC pass moves to bay storage
                              stamps stockyard_timestamp
                                    |
  Stage 6: LOADING      -->  DeliveryNotePage.tsx loads onto trailer
                              stamps loading_timestamp
                                    |
  Stage 7: DISPATCH     -->  DeliveryNotePage.tsx gate-out
                              stamps dispatch_timestamp
                                    |
  Stage 8: DELIVERY     -->  DeliveryNotePage.tsx site receipt
                              stamps delivery_timestamp

  QR CODE ENCODING FORMAT (per element):
  {
    "id": "00-WL02-2525M-012",
    "project": "SP2544P",
    "type": "Solid Wall",
    "status": "Ready"
  }
